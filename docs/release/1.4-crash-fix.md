# 1.4 (325) startup crash fix

Date: 2026-11-10

All 12 supplied crash reports (1.3/323 and 1.4/324) terminate on the main thread with SIGABRT. The shared stack is Kakao `createPoiStyle` -> `convertBitmapObjectToImageData` -> `ImageData::_setPixelSize` -> C++ throw/abort. The earlier coordinate guards did not address this failure.

Normalize every POI image at the SDK boundary to explicit sRGB, 8-bit components, 32-bit premultiplied RGBA. Preserve display size, scale and transparency. Reject invalid/oversized images instead of handing them to the native decoder. Extended-range or grayscale image output is a plausible input trigger; the logs do not identify the individual source image.

Regression tests cover 16-bit floating-point images, grayscale images, PNG encoding, dimensions and empty images. The release workflow runs these tests on an iPhone simulator before archiving. Local Windows validation is limited to static inspection and diff checks; Codemagic and physical-device verification remain required.
