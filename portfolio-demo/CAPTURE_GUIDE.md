# 실제 앱 화면 녹화를 영상에 넣기

현재 영상의 앱 화면(S2–S5)은 SwiftUI 뷰 구조를 옮긴 구성도다. 이 작업 환경(WSL)에는
macOS도 Xcode도 없어서 시뮬레이터를 띄울 수 없기 때문이고, 그래서 화면마다
`SwiftUI 뷰 구조를 옮긴 구성도 · 실행 화면 캡처 아님` 배지를 달아 두었다.

실제 실행 화면 녹화를 주면 그 자리에 그대로 끼운다. 파이프라인은 이미 만들어 두었고
더미 영상으로 동작을 확인했다. 녹화만 있으면 된다.

## 필요한 녹화 4개

각 구간 길이에 맞춰 **조금 넉넉히**(8~10초) 찍어 주면, 필요한 구간만 잘라 쓴다.

| 장면 | 영상 길이 | 무엇을 보여줘야 하나 |
|---|---|---|
| `s2` 지도 | 5.2초 | 지도에 핀이 떠 있는 상태에서 축제/공연/주차 토글을 한 번 눌러 핀이 바뀌는 모습 |
| `s3` 상세 | 5.2초 | 행사 상세 화면을 위로 천천히 스크롤 — 기간·장소·요금·프로그램이 지나가게 |
| `s4` 캘린더 | 5.2초 | 캘린더 탭에서 날짜를 하나 눌러 아래 목록이 그 날짜로 바뀌는 모습 |
| `s5` 주차 | 5.4초 | 행사 상세에서 주변 주차장으로 넘어가 주차장 목록/지도가 보이는 모습 |

동작은 **천천히, 한 화면에 한 가지만**. 빠른 전환은 5초짜리 컷에서 무슨 일이 일어났는지
읽히지 않는다. 화면 녹화 중에는 알림 배너가 뜨지 않게 방해 금지 모드를 켜는 편이 좋다.

## 녹화 방법

**시뮬레이터 (Mac + Xcode)**

```bash
xcrun simctl list devices booted          # 부팅된 기기 확인
xcrun simctl io booted recordVideo --codec h264 ~/Desktop/s2-map.mov
# 녹화를 끝낼 때 Ctrl+C
```

`--codec h264`를 주면 파일이 작고 어디서나 열린다. 기본값(HEVC)도 처리는 되지만 굳이.

**실기기 (Mac 없이도 됨)**

설정 → 제어 센터에 `화면 기록`을 추가하고, 앱을 띄운 상태에서 녹화 → 사진 앱에서
`파일에 저장`으로 mp4/mov를 꺼낸다. 실기기 쪽이 오히려 낫다: 실제 API에 붙은 진짜 데이터가
찍히고, 스크롤 감속 같은 손맛도 그대로 남는다.

## 파일 전달

WSL에서 읽을 수 있는 경로에 두면 된다. Windows 쪽에 있다면 `/mnt/c/Users/<이름>/Desktop/...`로
그대로 접근된다. 파일 이름은 `s2-map.mov`처럼 장면 id를 앞에 붙여 주면 헷갈리지 않는다.

원본 녹화 파일은 저장소에 커밋하지 않는다(`.gitignore`에서 `assets/capture/`를 제외한다).

## 붙이는 절차

```bash
cd portfolio-demo
scripts/import-capture.sh ~/Desktop/s2-map.mov s2 3 5.2
#                          녹화 파일          장면  시작초 길이
```

30fps JPEG 시퀀스를 `assets/capture/s2/`에 만들고, 프레임 수와 함께
"이 비율이면 `.phone` 높이를 N px로 맞춘다"를 알려준다. 실기기 화면비(대개 1:2.17)와
지금 폰 프레임(404×800 = 1:1.98)이 달라서, 높이를 맞추지 않으면 위아래가 잘린다.

그다음 `src/index.html`에서 해당 장면의 구성도 마크업을 지우고 한 줄로 바꾼다:

```html
<div class="phone" data-at="0.2" data-dy="26">
  <img class="pcap" data-capture="s2" data-cap-frames="156" alt="">
</div>
```

`window.seek(t)`가 장면 로컬 시간에 맞는 프레임을 넣고 디코딩이 끝날 때까지 기다리므로,
렌더는 지금과 똑같이 결정론적이다.

마지막으로 정직성 표시를 실제에 맞게 고친다 — 이걸 빠뜨리면 영상이 거짓말을 하게 된다:

- 그 장면의 `.badge` 문구를 `iOS 시뮬레이터 실행 화면 녹화` 또는 `실기기 실행 화면 녹화`로 바꾼다.
- `ASSETS.md`의 "실제 앱 스크린샷 없음" 항목과 표를 갱신한다.
- `FACT_CHECK.md` §7에서 "실제 실행 화면 캡처를 넣지 않았다" 항목을 지운다.

네 장면 전부 교체하면 배지 자체를 없애도 된다.

## 확인

```bash
node render.mjs --preview 12     # 그 장면 한 컷만 PNG 로
node render.mjs                  # 전체 재렌더 (약 4분 20초)
```
